# Privacy

Fueling App is in private development. It isn't available to the public, and only its developer uses it.

During development the app connects only to the developer's own Intervals.icu account. It reads planned workouts and doesn't write anything to Intervals.icu. It doesn't sell that data or use it for advertising.

A full privacy policy will replace this page before anyone else can install the app or connect an account.

Questions: open an issue at https://github.com/Diegod96/Personalized-Nutrition-Application/issues
